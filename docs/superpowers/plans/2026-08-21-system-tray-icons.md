# System Tray Icon Replacement Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the procedural Audio, AirPlay, and Wi-Fi tray graphics with pinned Phosphor Icons Bold bitmaps and give them one enforced `20×20 px` system tray contract.

**Architecture:** Vendor four single-path SVG files, rasterize them offline into checked-in tight-packed I1 arrays, and keep the existing runtime paths. Audio and AirPlay continue through `app_core::tray_registry`; Wi-Fi keeps its existing create/update API but switches between two persistent LVGL I1 canvases. Battery remains an independently sized `30×14 px` status component.

**Tech Stack:** C++17, ESP-IDF, LVGL 9.3, Python 3, NumPy, existing host-test harness.

## Global Constraints

- Use Phosphor Icons Core commit `2b75f3ad12b420c9504ef05df8d2564a28f8500e`.
- Use `speaker-high-bold`, `airplay-bold`, `wifi-high-bold`, and `wifi-slash-bold`.
- Rasterize every new icon with `--width 20 --height 20 --fit viewbox --threshold 0.35 --min-stroke 1`.
- Store runtime icon data as tight-packed I1, row-major, MSB-first, `3 bytes` per row and `60 bytes` per icon.
- Keep the system tray height at `28 px` and its gaps unchanged.
- Keep battery at `30×14 px`; do not convert it into a pure icon.
- Keep tray ordering, slot priority, registry capacity, and cheap-update behaviour unchanged.
- Do not add runtime SVG decoding, a new icon framework, a CMake generation step, or a new dependency.
- Keep weather icons outside this change.
- Do not claim hardware appearance is approved until someone inspects the reflective panel.
- Do not run any `git commit` step unless the user explicitly authorizes commits.
- `TrayIndicatorBitmap` declares payload length as `uint8_t byte_count`; every
  registry caller supplies `sizeof(its_array)`, and registration requires
  `byte_count == kTrayIconBitmapBytes` before allocating a slot.

> **Implementation amendment — chosen contract:** payload-length validation is
> required. Valid tray registrations are non-null, 20×20, and exactly 60
> bytes. Audio and AirPlay pass `sizeof` their static arrays; tests cover a
> claimed 20×20 one-byte payload rejection.

```python
def pack_i1_bytes(mask: np.ndarray) -> bytes:
    """Packs a 2-D boolean mask row-major, MSB-first, padding each row."""
    if mask.ndim != 2:
        raise ValueError("mask must be a 2-D array")
    return np.packbits(mask, axis=1, bitorder="big").tobytes()


def to_cpp_bytes(mask: np.ndarray, name: str) -> str:
    packed = pack_i1_bytes(mask)
    lines = []
    for start in range(0, len(packed), 12):
        chunk = packed[start:start + 12]
        lines.append("    " + ", ".join(f"0x{value:02x}" for value in chunk) + ",")
    body = "\n".join(lines)
    return f"constexpr uint8_t {name}[] = {{\n{body}\n}};\n"
```
